## 📌 F. Tugas OBE

### Tugas 1 — Analisis Request-Response dan Setup Repository

Memilih satu situs layanan publik/pendidikan yang dapat diakses, menganalisis minimal lima *request* pada tab **Network**, tanpa mencoba mengubah atau mengganggu sistem. Dokumentasi mencakup *method*, *status*, *content type*, ukuran, dan fungsi dari setiap *request*. Selain itu, dibuat repository proyek semester dengan *commit* fondasi awal.

> **Situs yang dianalisis:** `akademik.ubt.ac.id`

## 🧠 H. Refleksi Mahasiswa

### 1. Konsep apa yang paling dipahami?
Konsep utama yang dipahami adalah mekanisme arsitektur web berbasis *client-server* serta alur komunikasi HTTP/HTTPS, khususnya interaksi *request-response* yang diamati langsung melalui **Network tab** pada portal akademik (`akademik.ubt.ac.id`). Dari pengamatan tersebut, dipahami penggunaan *Request Method* **GET** dengan *Status Code* **200 OK** untuk mengambil berbagai sumber daya — mulai dari dokumen HTML utama, *stylesheet* berbasis ZK Framework, berkas JavaScript untuk logika antarmuka, aset SVG untuk navigasi, hingga font WOFF2 agar tampilan sesuai desain asli. Selain itu, dikuasai pula dasar-dasar *version control* dengan Git/GitHub serta penyiapan server lokal menggunakan Laragon.

### 2. Kendala yang ditemukan dan solusinya
Kendala teknis tergolong minim, umumnya berupa kesalahan pengetikan (*typo*) saat memasukkan perintah pada terminal Git. Solusinya adalah memeriksa ulang sintaks secara teliti dan menjalankan kembali perintah dengan benar.

### 3. Bukti validitas hasil
Kevalidan hasil praktikum dibuktikan melalui kelengkapan dokumentasi tugas, tangkapan layar environment server lokal Laragon, tabel hasil analisis jaringan, serta riwayat *commit* dan struktur berkas yang terpusat pada repositori:
🔗 [`github.com/Blanchette756/PRAKTIKUM-1`](https://github.com/Blanchette756/PRAKTIKUM-1)

### 4. Penggunaan AI dan verifikasinya
AI dimanfaatkan untuk membantu penyusunan draf dokumentasi (`README.md`), pencatatan log penggunaan AI, serta referensi sintaks perintah Git. Seluruh hasil keluaran AI diverifikasi dan disesuaikan secara mandiri untuk memastikan keakuratan teknis serta kepatuhan terhadap modul praktikum Pemrograman Web.
